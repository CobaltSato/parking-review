# Parking Review

DIMOネットワークと連携した駐車場レビューアプリケーション。

## 📋 仕様

### 概要

Parking Reviewは、DIMOプラットフォーム上で駐車場の混雑状況やレビューを収集・共有する機能です。ドライバーが駐車場を利用した際の情報を収集し、他のドライバーが駐車場を選択する際の判断材料として活用できます。

**問題提起**
目的地に着いたときに必ずしなければならないことは何でしょうか？それは「駐車場を探す」ことです。Parking Reviewは、この駐車体験をアップデートするソリューションです。

### 主要機能

#### 1. アンケート収集

**表示タイミング**
- DIMOセッション終了時に、ポップアップモーダルでアンケートを表示
- ユーザーがログイン状態でアプリにアクセスした際に自動表示

**必須項目**
- 駐車場の利用有無（「利用した」/「利用していない」）
- 混雑状況（5段階評価）
  - 空いている
  - やや空いている
  - 普通
  - やや混雑
  - かなり混雑

**任意項目**
- コメント（テキスト）
- 写真（複数枚アップロード可能）
- 駐車場の広さ

**位置情報連携**
- GPS位置情報から、どの駐車場かを自動判定
- ユーザーは駐車場を手動で選択する必要がない
- 行き先とレビューデータで駐車場を紐付け

**送信と報酬**
- アンケート送信後、成功モーダルを表示
- 報酬として10 JPYCを付与
- ユーザーの回答は、次の人の判断に使用されることを通知

#### 2. 駐車場情報の閲覧

**基本情報の表示**
- 駐車場名（例：カフェ・ド・パリ）
- 位置情報（地図表示）
- 直近の混雑状況
  - 例：「直近15分で、2人が「やや混雑（駐車場）」と感じています」

**駐車場の様子**
- 駐車場の写真を確認できる
- 複数の写真をカルーセル形式で表示
- ドライバーが投稿した写真を閲覧可能

**利用者からの情報**
- ドライバーのレビューを閲覧
- レビューには以下の情報が含まれる：
  - ドライバーID（例：ドライバー #338）
  - レビューテキスト
  - タグ（例：「駐車しやすさ」「駐車場写真提供」）
  - 投稿された写真
- 「すべて見る」リンクで全レビューを閲覧可能

#### 3. マイページ

**表示内容**
- ウォレットアドレス（全桁表示、モバイルでは省略表示）
- コピー機能（クリックでコピー）
- PolygonScanリンク（新しいタブで開く）

### データの統合

#### 既存データとの連携

**車両から生まれるデータ**
- エンジン負荷
- エンジン回転数
- 車速
- 吸気温度
- 燃料残量
- その他の車両センサーデータ

**レビューデータとの統合**
- 行き先とレビューデータで駐車場を紐付け
- 車両データとレビューデータを組み合わせて、より精度の高い情報を提供

### データのユースケース

#### 1. 駐車場情報の閲覧（その1）

収集したデータを活用して、以下の情報を提供できます：

- **ドライバーのレビューがわかる**
  - 実際に駐車場を利用したドライバーからの生の声
  - 駐車のしやすさ、混雑状況などの実体験

- **駐車場の写真を確認できる**
  - ドライバーが投稿した実際の駐車場の写真
  - 複数の角度からの写真で駐車場の様子を把握

- **Googleマップと連携**
  - Googleマップ上に駐車場情報を表示
  - 地図上で混雑状況やレビューを確認可能

#### 2. カーナビ連携（その2）

**機能概要**
カーナビ連携で状況を教えてくれる機能です。

**通知内容**
- 目的地到着前に通知
- 例：「目的地までおよそ10分です。15分前に2台の車がやや混雑と感じています。」

**提供される情報**
- 混雑状況やドライバーのレビューを見たり
- 駐車場の写真を確認したり
- Googleマップと連携

**ユーザー体験の流れ**
1. カーナビで目的地に向かう途中、通知が表示される
2. 駐車場の混雑状況を確認
3. 到着後、実際に駐車場を利用
4. DIMO終了時に、ポップアップでレビューを投稿
5. 他のドライバーがその情報を活用
