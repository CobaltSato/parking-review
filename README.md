# Parking Review

DIMOネットワークと連携した駐車場レビューアプリケーション。

## 🚀 クイックスタート

### インストール

```bash
npm install
```

### 環境変数の設定

`.env`ファイルを作成：

```env
REACT_APP_DIMO_CLIENT_ID=your-client-id
REACT_APP_DIMO_REDIRECT_URI=http://localhost:3000
REACT_APP_DIMO_ENV=development
REACT_APP_DIMO_API_KEY=your-api-key
```

### 起動

```bash
npm start
```

## 📦 ビルド

```bash
npm run build
```

## 🧪 テスト

```bash
npm test
```
